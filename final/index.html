El Pasima - Site Plan

Site Name

El Pasima

I chose this name because I want to build a crypto trading platform, and this project lets me design and develop it as part of my coursework.

Site Purpose

El Pasima will be a simple three-page site for a crypto trading platform: a homepage introducing the platform and what it offers, a page explaining how trading/exchange works on the platform, and a page with pricing or account information for users.

Scenarios

  • What does El Pasima offer?
  • How does trading work on El Pasima?
  • How much does it cost to use El Pasima?

Color Scheme

  • Dark Navy (#0d1b2a) - used for the header, footer, and section backgrounds
  • Gold (#f5a623) - used for headings, buttons, and accents

Typography

Inter - Bold (700 weight) is used for headings; Regular (400 weight) is used for body text.
